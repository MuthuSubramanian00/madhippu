# Security

madhippu reads untrusted PDFs, so problems such as a crafted PDF that makes
it hang, exhaust memory, or write unexpected content (for example, a formula
in an Excel cell) are in scope.

Please report vulnerabilities privately through GitHub's "Report a
vulnerability" button on the repository's Security tab, not in a public
issue. You'll get a reply within a week.

Only the latest release is supported.
